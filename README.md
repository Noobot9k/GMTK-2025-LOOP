# The Dark Below
Game entry into GMTK 2025 game jam https://pc-hris.itch.io/gmtk-2025

You've been dumped in a well and must find a way out. It's a lot deeper than it looks from the surface...

If you experience performance issues, you can try pressing + and - to adjust the number of times the loop is rendered. If you still experience performance problems, please download the game instead of using the web build. The web player is not very performant.

This game was made using Godot 4.5beta4 I probably won't make another jam entry with Godot though. 60% of development time was just spent wrangling with technical issues. The compatibility renderer just ain't it.
